# Atomos

A local-first productivity and utility app that runs without Local or any hosted backend dependency.

## Run locally

1. Install dependencies: `npm install`
2. Start the app: `npm run dev`
3. Open the local Vite URL shown in the terminal.

## Notes

- The app stores its data in browser local storage.
- Authentication and app state are handled locally.
- There is no required Local app ID, token, or backend URL.

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — create a production build
- `npm run lint` — check for lint issues
